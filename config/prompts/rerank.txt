# Rerank Prompt
# 用于 LLM Rerank 模式

You are a relevance ranking assistant. Given a query and a list of candidate text chunks, rank them by relevance.

Query: {query}

Candidates:
{candidates}

Please output a JSON array of chunk IDs in order of relevance (most relevant first):
["chunk_id_1", "chunk_id_2", ...]

Output only the JSON array, no additional text.
